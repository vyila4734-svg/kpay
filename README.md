# KPay — цифровые покупки

Responsive frontend for digital purchases. Open `index.html` in a modern browser.

- Pure HTML, CSS and JavaScript; no build step or external API.
- `index.html` contains the page markup, `style.css` the styles, and `script.js` the interactions.
- Interactive Steam amount calculator with promo code `KPay10`, payment-method selection, Telegram Stars/Premium selectors, mobile menu, FAQ accordion and notifications.
- Prices and fees are estimates. Online payments, authentication, order processing, and external services are not available.
